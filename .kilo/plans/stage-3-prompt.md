## Что нужно реализовать

### 1. Замена заглушки `#tab-passport`

Убрать текст-заглушку. Секция `#tab-passport` должна содержать:
- Заголовок экрана: «Мой паспорт».
- Общий прогресс: **«X из 57»** (крупно, вверху).
- Внутренний контейнер `#passport-list` для динамического рендера аккордеонов.

Всё содержимое генерируется функцией `renderPassport()` в `app.js`.

### 2. Аккордеоны регионов

**7 блоков** (по одному на регион), порядок — как в массиве `REGIONS`. Каждый аккордеон состоит из:

**Заголовок (обложка):**
- Название региона (из `REGIONS.name`).
- Цветной индикатор — небольшой кружок или полоска слева, цвет из `REGIONS.color`.
- Счётчик: «Y из Z» (Y — посещённые, Z — всего городов в регионе).
- Стрелка-индикатор раскрытия (▼ / ▲ или CSS-поворот).
- **Тап-область заголовка — не менее 44×44px.**
- Если все города региона посещены (100%) — на обложке отображается **метка достижения** (см. пункт 5).

**Тело аккордеона (при раскрытии):**
- Скрыто по умолчанию. Раскрывается плавно через современный CSS Grid: анимируй `grid-template-rows` от `0fr` до `1fr` для обёртки контента. **Не используй** хак с `max-height: 1000px` — он даёт рваную анимацию. **Не используй** `display: none / block` — это ломает анимацию `grid-template-rows`.
- Внутри — **CSS Grid** с ячейками штампов городов.

**Логика раскрытия:**
- Тап по заголовку — toggle (раскрыть/свернуть).
- Одновременно может быть раскрыто несколько аккордеонов (не mutually exclusive).

### 3. Сетка штампов

Внутри раскрытого аккордеона — CSS Grid с ячейками. Каждая ячейка — один город.

**Рекомендуемая сетка:** адаптивный CSS Grid: `grid-template-columns: repeat(auto-fill, minmax(70px, 1fr)); gap: 10px;`. Это обеспечивает автоматическое распределение колонок без медиа-запросов и корректное отображение от 320px до 430px.

**Ячейка штампа:**
- **Обязательные классы и атрибуты:** каждая ячейка имеет CSS-класс `stamp-cell` и `data-city-id="<id>"`.
- **Непосещённый город:** серый силуэт штампа. Визуально — приглушённый, полупрозрачный или серый контур. В центре — серая мини-иконка. Под силуэтом — название города мелким серым текстом.
- **Посещённый город:** яркий цветной штамп. Цвет — из `REGIONS.color`. В центре — мини-иконка штампа (та же структура, что у силуэта, но яркая и цветная). Под штампом — название города.
- **Тап-область каждой ячейки — не менее 44×44px.**

### 4. Графика штампов — inline SVG

Штамп — это единая SVG-структура, вставленная инлайн. **Все SVG-шаблоны** обязаны использовать атрибут `viewBox` (например, `viewBox="0 0 100 100"`) и **не иметь** жёстких `width`/`height` в атрибутах тега `<svg>` — масштабирование происходит исключительно через CSS (`width: 100%; height: auto;`). Это критично для адаптивности в Grid-сетке.

**Штамп состоит из двух частей:**
1. **Внешний контур** — одинаковая форма для всех регионов: зубчатый круг или круг с прорезями.
2. **Внутренняя иконка** — уникальная для каждого региона (7 вариантов, см. ниже).

**Цвет штампа:** используй `fill="currentColor"` для всех элементов (контур и иконка). Фактический цвет задавай через CSS-свойство `color` на обёртке `.stamp-icon` или самой ячейке: `color: #ccc` для серых силуэтов, `color: var(--region-color)` для посещённых.

**Иконки регионов:** Создай объект `REGION_ICONS`, где ключ — `regionId`, значение — SVG-строка **только внутренней иконки** (без внешнего контура). Например:
```js
const REGION_ICONS = {
  minsk: '<path d="...ратуша..." fill="currentColor"/>',
  minsk_obl: '<path d="...замок..." fill="currentColor"/>',
  brest: '<path d="...крепость..." fill="currentColor"/>',
  grodno: '<path d="...башня..." fill="currentColor"/>',
  vitebsk: '<path d="...храм..." fill="currentColor"/>',
  mogilev: '<path d="...ратуша..." fill="currentColor"/>',
  gomel: '<path d="...дворец..." fill="currentColor"/>',
};
```

**Функция `createStampSVG(regionId)`** возвращает полный SVG-элемент штампа: внешний зубчатый контур + вписанная внутрь иконка из `REGION_ICONS[regionId]`. Все части с `fill="currentColor"`. Размеры иконки подбирай так, чтобы она гармонично вписывалась в контур (занимала ~50–60% ширины/высоты).

Иконки — максимально простые, 1–2 контурные линии. Это не дизайн-шедевры, а узнаваемые силуэты для MVP.

### 5. Геймификация (метки достижений)

Если **все** города региона посещены — на заголовке аккордеона появляется метка:
- **Для Минска** (1 город): серебряная метка **«Старт»**. Цвет текста/фона — серебряный (#C0C0C0).
- **Для остальных 6 регионов** (8–10 городов): золотая метка **«Пройден»**. Цвет текста/фона — золотой (#FFD700 или аналогичный).

**Логика появления/исчезновения:**
- Метка отображается строго при 100% заполнении региона.
- При удалении одного города из полностью закрытого региона (через toggle в Каталоге) — метка **автоматически снимается**.
- Эта логика проверяется через перерендер: при каждом вызове `renderPassport()` заново вычисляется, какие регионы закрыты.

### 6. Тап по ячейке города

По тапу на ячейку штампа (посещённого или нет) — пока **ничего не происходит**. Это заглушка для Этапа 4. Просто убедись, что ячейки имеют класс `.stamp-cell` и `data-city-id`.

## Сохранение состояния раскрытых аккордеонов

Добавь в `state` поле:
```js
openedRegions: []  // массив regionId раскрытых аккордеонов
```
Это **ephemeral-состояние** — оно **не сохраняется** в localStorage (не включай его в `saveState()`). Живёт только в памяти на время сессии.

**Логика:**
- При тапе на заголовок: если `regionId` уже в `openedRegions` — удалить (свернуть). Если нет — добавить (раскрыть).
- При вызове `renderPassport()`: после генерации DOM для каждого аккордеона, чей `regionId` есть в `openedRegions`, добавь CSS-класс `open` к корневому элементу аккордеона (`.accordion-item.open`). В CSS пропиши `.accordion-item.open .accordion-body { grid-template-rows: 1fr; }` — именно это раскроет тело анимацией.
- **Важно:** не используй `display: none/block` для тела аккордеона — ломает анимацию.

**Это гарантирует:** пользователь раскрыл «Брестскую область», переключился в Каталог, отметил Пинск, вернулся в Паспорт → аккордеон «Брестская область» **всё ещё раскрыт**, а новый штамп Пинска уже на месте.

## Изменения в style.css

- **Аккордеоны:** стили заголовка (курсор, hover/active, стрелка), стили тела (скрыто/раскрыто, плавный transition через `grid-template-rows: 0fr → 1fr`). Для корректной работы анимации внутри анимируемого контейнера `.accordion-body` должна быть дополнительная обёртка `.accordion-inner` со свойством `overflow: hidden` — иначе контент будет вылезать за пределы скрытого блока при нулевой высоте. Структура:
  ```html
  <div class="accordion-body">  <!-- grid-template-rows: 0fr / 1fr -->
    <div class="accordion-inner">  <!-- overflow: hidden -->
      <div class="stamps-grid">...</div>
    </div>
  </div>
  ```
- **Сетка штампов:** CSS Grid `repeat(auto-fill, minmax(70px, 1fr))`, ячейки с выравниванием, отступы.
- **Штампы:** стили для посещённых (`color: var(--region-color)`) и непосещённых (`color: #ccc`). SVG через `fill="currentColor"` масштабируется через CSS `width: 100%; height: auto;`.
- **Метки достижений:** золотая и серебряная метки на заголовке аккордеона (badge/метка).
- Все active-элементы — **не менее 44×44px** тап-область.

## Изменения в app.js

1. **SVG-шаблоны:** объект `REGION_ICONS` с 7 иконками (только `<path>` с `fill="currentColor"`) и функция `createStampSVG(regionId)`, возвращающая полный штамп (общий контур + иконка региона).
2. **Функция `renderPassport()`** — генерирует всё содержимое `#passport-list`:
   - Перебирает `REGIONS`.
   - Для каждого региона: считает прогресс, определяет закрытие, строит аккордеон (заголовок + тело с сеткой).
   - Для каждого города: проверяет `state.visitedCities[cityId]`, рисует серый силуэт или цветной штамп через `createStampSVG`.
   - Добавляет метку «Пройден» / «Старт» при 100%.
   - После генерации DOM восстанавливает раскрытие: для `regionId` из `state.openedRegions` добавляет класс `open` на аккордеон.
3. **Обработчик кликов по аккордеонам:** меняет `state.openedRegions`, затем toggle класса `open` на аккордеоне (без полной перерисовки — это быстрее и не сбрасывает анимацию). Полная перерисовка происходит только при переключении вкладок.
4. **Обновить функцию переключения вкладок:** при переключении на `passport` вызывать `renderPassport()`.
5. **Обновить `init()`:** если `state.currentTab === 'passport'` при старте — вызвать `renderPassport()`.
