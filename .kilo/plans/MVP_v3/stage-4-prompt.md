## Текущее состояние функций (изучи по app.js)

**`REGIONS` (строки 3–11):** Массив из 7 объектов `{id, name, color}`. Цвета регионов используются как `currentColor` для штампов.

**`REGION_ICONS` (строки 13–21):** Объект с SVG-path иконками для каждого региона. Каждая иконка — `<path fill="currentColor">`. Используется внутри `createStampSVG`.

**`createStampSVG(regionId, tier)` (строки 23–47):** Функция **уже обновлена** — принимает `tier` (default `"bronze"`), формирует tier-зависимые элементы:
- `viewBox="0 0 100 100"`
- Для **Silver**: серебряное кольцо `<circle r="47" stroke="#C0C0C0" opacity="0.8">` перед штампом
- Для **Gold**: золотое кольцо `<circle r="47" stroke="#FFD700" opacity="0.6">` + обёртка `<g>` вокруг зубчатого круга и иконки
- Зубчатый круг (path с множеством точек) — `fill="none" stroke="currentColor" stroke-width="2.5" opacity="0.5"`
- Внутренняя иконка региона (`REGION_ICONS[regionId]`) — `fill="currentColor"`, сдвинутая через `translate(0, 10)`
- Вся разметка обёрнута в `<g transform="translate(0, 10)">`

> **⚠️ Проблема на строке 34:** Текущий код использует `'<g style="color:#FFD700">'` (inline CSS). Для SVG, парсимого через `innerHTML`, надёжнее использовать SVG presentation attribute `'<g color="#FFD700">'` (см. задачу 1). Это **единственная правка** в коде на этом этапе.

## Задачи

### 1. `app.js` строка 34 — заменить inline style на SVG presentation attribute

**Единственная правка в коде на этом этапе.** Строка 34 внутри `createStampSVG()`, ветка `tier === "gold"`.

**Было:**

```javascript
    openTag = '<g style="color:#FFD700">';
```

**Стало:**

```javascript
    openTag = '<g color="#FFD700">';
```

Больше ничего в функции не менять — сигнатура, `ring`, `closeTag`, SVG path зубчатого круга, иконки — всё корректно.

> **⚠️ Почему `color` вместо `style="color:..."`:** SVG, парсимый через `innerHTML`, в старых браузерах (iOS Safari < 13) некорректно резолвит `currentColor` из inline `style="color:..."`. Presentation attribute `color` наследуется через `currentColor` надёжнее во всех браузерах. Поскольку PWA работает на `file:///` и потенциально в старых WebView-оболочках — выбираем максимально совместимый вариант.
>
> **⚠️ Как это работает после правки:**
> - **Бронза** (и `null`/`undefined`): `tier = "bronze"` → ни `ring`, ни `openTag`/`closeTag` не формируются. Штамп рисуется как в v2 — зубчатый круг и иконка в `currentColor` (цвет региона). Визуально идентичен v2.
> - **Серебро:** добавляется `<circle r="47">` с серебряной обводкой **перед** штампом. Сам штамп не меняется — остаётся в цвете региона. Кольцо визуально «окаймляет» зубчатый круг.
> - **Золото:** добавляется золотой `<circle r="47">` **перед** штампом, и весь штамп (зубчатый круг + иконка) оборачивается в `<g color="#FFD700">`. Поскольку зубчатый круг использует `stroke="currentColor"` и иконка использует `fill="currentColor"`, обёртка `<g color="#FFD700">` перекрашивает **всё** в золото.
>
> **⚠️ Порядок элементов в SVG = z-order:** Кольцо (`ring`) идёт **первым**, перед зубчатым кругом. Это правильно — кольцо рисуется «под» штампом, создавая эффект рамки.
>
> **⚠️ `tier = null` для непосещённых городов:** Функция получает `null` → `tier = tier || "bronze"` → `"bronze"`. Штамп рисуется bronze-формы, но цвет берётся из CSS/inline-style родителя (`color: #ccc` для непосещённых). Серый силуэт bronze-штампа — корректное поведение.

## Критерии готовности
