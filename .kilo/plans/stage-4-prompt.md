## Что нужно реализовать

### 1. Карточка города — полноэкранный оверлей

**UI:** полноэкранный оверлей поверх текущего контента с затемнённым фоном.

**Позиционирование:**
- `position: fixed; top: 0; left: 0; width: 100%; height: 100%; z-index: 100;`
- Фон — полупрозрачный тёмный (например, `rgba(0,0,0,0.5)`).
- Контент карточки — центрирован по вертикали и горизонтали, ширина `max-width: 430px`.
- **Tab Bar остаётся видимым**, но блокируется: `pointer-events: none` на Tab Bar пока оверлей открыт.
- Кнопка закрытия ✕ в правом верхнем углу карточки (тап-область ≥ 44×44px).

**Содержимое карточки (рендерится динамически по `cityId`):**
- Название города (крупно).
- Название региона (из `REGIONS` по `city.region`).
- Описание (из `CITIES[].description`).
- Миниатюра штампа — через `createStampSVG(city.region)` (функция уже существует из Этапа 3).

**Два состояния карточки:**

**А) Город НЕ посещён:**
- Отображается серый штамп.
- Кнопка **«Я здесь был»** (≥ 44×44px).
- По нажатию → модальное окно выбора даты (см. пункт 2).

**Б) Город посещён:**
- Отображается цветной штамп (цвет региона).
- Дата визита: формат **ДД.ММ.ГГГГ** (преобразование из `YYYY-MM-DD`).
- Кнопка **«Удалить отметку»** (≥ 44×44px, красный/тревожный цвет).
- По нажатию → удаление (см. пункт 3).

### 2. Модальное окно выбора даты

Вызывается при нажатии «Я здесь был» в карточке города.

**UI:** модальное окно поверх карточки (ещё один слой, `z-index: 200`).

**Содержимое:**
- Заголовок: «Когда вы посетили <название города>?».
- `<input type="date">` — **обязательные атрибуты:**
  - `max` = сегодняшняя дата (локальная!). Вычисляется при каждом открытии модалки:
    ```js
    const today = new Date().toLocaleDateString('sv-SE'); // YYYY-MM-DD в локальной зоне
    ```
    **Не используй `toISOString()`** — при UTC+3 после 21:00 дата перескочит на завтра.
  - Значение по умолчанию = `today`.
- Кнопка **«Подтвердить»** — сохраняет выбранную дату в `state.visitedCities[cityId] = { date: selectedDate }`, вызывает `saveState()`, закрывает модалку, закрывает карточку города, показывает экран «Штамп получен» (Этап 5, пока заглушка).
- Кнопка **«Отмена»** — закрывает модалку без изменений.

**Тап-области:** все кнопки ≥ 44×44px. Инпут даты — ≥ 44px высота.

### 3. Удаление отметки

По нажатию «Удалить отметку» в карточке:

1. `delete state.visitedCities[cityId]`.
2. `saveState()`.
3. Закрыть карточку города.
4. **Не вызывать перерендер немедленно** — при следующем переключении на нужную вкладку `render*()` отработает автоматически с актуальными данными.

**Каскадные эффекты удаления** (происходят автоматически при перерендере):
- В Паспорте: штамп становится серым, счётчик региона уменьшается, золотая/серебряная метка снимается (если регион был закрыт).
- В Каталоге: город теряет визуальную отметку.
- В Профиле: Хроника и статистика пересчитываются.

### 4. Рефакторинг Каталога — УДАЛИТЬ временную toggle-механику

**Это ключевая задача этапа.** Временная toggle-механика из Этапа 1 **полностью удаляется**.

**Было (Этап 1):**
- Клик по `.city-item` в `#catalog-list` → toggle `state.visitedCities[cityId]` с `date: today`.

**Стало (Этап 4):**
- Клик по `.city-item` в `#catalog-list` → открыть карточку города (вызов `openCityCard(cityId)`).
- **Удалить весь код toggle-механики** из обработчика делегирования событий в Каталоге.
- **Удалить функцию или блок кода**, который напрямую модифицировал `visitedCities` из Каталога.

### 5. Навигация на карточку из Паспорта

Тап по ячейке `.stamp-cell` в `#passport-list` → открыть карточку города (`openCityCard(cityId)`).

Обработчик уже частично существует (заглушка через делегирование на `#passport-list` + `event.target.closest('.stamp-cell')`). Заменить заглушку на вызов `openCityCard(data-city-id)`.

### 6. Переменная `stampOrigin` для Этапа 5

При открытии карточки города сохраняй, откуда пришёл пользователь:

```js
state.stampOrigin = 'catalog' | 'passport' | 'map';
```

Значение определяется по `state.currentTab` в момент открытия карточки. Это нужно для Этапа 5 (экран «Штамп получен»), чтобы кнопка «В коллекцию» знала, куда возвращать.

`stampOrigin` — **ephemeral**, не сохраняется в localStorage.

## Функции для добавления в app.js

1. **`openCityCard(cityId)`** — устанавливает `state.activeOverlayCityId = cityId`, сохраняет `state.stampOrigin`, вызывает `renderCityCard(cityId)`, показывает оверлей `#city-card-overlay`, блокирует Tab Bar.

2. **`closeCityCard()`** — устанавливает `state.activeOverlayCityId = null`, скрывает оверлей, разблокирует Tab Bar.

3. **`renderCityCard(cityId)`** — генерирует содержимое карточки на основе данных города из `CITIES` и состояния посещённости из `state.visitedCities`.

4. **`openDatePicker(cityId)`** — показывает модалку выбора даты.

5. **`confirmVisit(cityId, date)`** — записывает `state.visitedCities[cityId] = { date }`, `saveState()`, закрывает модалку и карточку, показывает экран «Штамп получен» (пока — `console.log('Штамп получен:', cityId)`, экран реализуется на Этапе 5).

6. **`removeVisit(cityId)`** — `delete state.visitedCities[cityId]`, `saveState()`, закрывает карточку.

## Изменения в style.css

- **Оверлей карточки города:** `position: fixed; top: 0; left: 0; width: 100%; height: 100%; z-index: 100; background: rgba(0,0,0,0.5);`. Внутренний контент центрирован, `max-width: 430px`. **Критично для мобильных:** обязательно задай `overflow-y: auto; padding: 20px 10px;`. Центрирование — через `display: flex; align-items: center; justify-content: center;`. На маленьких экранах (iPhone SE) длинные описания могут вытолкнуть кнопки за край — скролл должен работать.
- **Модалка выбора даты:** `position: fixed; z-index: 200;` — поверх карточки. Центрированная, с белым фоном, скруглёнными углами.
- **Стили карточки:** название, регион, описание, штамп, кнопки «Я здесь был» / «Удалить отметку».
- **Кнопка ✕:** правый верхний угол, ≥ 44×44px.
- **Блокировка Tab Bar:** класс `.tab-bar-blocked { pointer-events: none; opacity: 0.5; filter: grayscale(50%); }` — не только отключает клики, но и визуально приглушает Tab Bar, чтобы пользователь считывал, что меню временно неактивно.
- Все кнопки и инпуты — **≥ 44×44px** тап-область.

