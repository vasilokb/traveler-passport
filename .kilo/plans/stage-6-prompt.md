## Часть 1. Edge cases — защита

### 1.1. Сброс localStorage браузером

Браузер на мобильных устройствах может очистить localStorage при нехватке памяти (особенно на iOS Safari в режиме Private Browsing — `quota exceeded`).

**Защита:**
- Оберни все вызовы `localStorage.setItem()` в `try/catch`. Если выброшено исключение `QuotaExceededError` или любое другое — показать пользователю тост-предупреждение: *«Не удалось сохранить данные. Освободите место в браузере.»*
- Оберни `localStorage.getItem()` в `try/catch`. Если данные повреждены (невалидный JSON) — инициализировать `state` дефолтными значениями, не крашить приложение.

### 1.2. Экстремально длинное имя путешественника

Пользователь может ввести имя длиной в 50 символов (установлен `maxlength="50"`). На экране Профиля и в тексте шаринга это может сломать верстку.

**Защита:**
- Везде, где отображается `state.travelerName` — добавь CSS-свойство `overflow: hidden; text-overflow: ellipsis; white-space: nowrap;` с `max-width`, чтобы длинное имя обрезалось многоточием, а не ломало layout.
- В тексте шаринга (Web Share API / clipboard) — имя выводится полностью, ограничение только визуальное.

### 1.3. Пустой ввод имени при онбординге

Если пользователь ввёл только пробелы и нажал «Продолжить» — `state.travelerName` будет содержать строку из пробелов.

**Защита:**
- Перед сохранением имени — `trim()`. Если после `trim()` строка пустая — сохранить дефолтное значение «Белорусский путешественник».

### 1.4. Повреждённые данные в localStorage

Если между сессиями пользователь вручную редактировал localStorage (или данные повреждены) — `visitedCities` может содержать невалидные записи (нет поля `date`, `date` не в формате `YYYY-MM-DD`, `cityId` не существует в `CITIES`).

**Защита:**
- В `loadState()` после парсинга JSON — валидация:
  - `visitedCities` должен быть объектом (не массивом, не строкой).
  - Каждая запись должна иметь строку `date` в формате `YYYY-MM-DD` (проверка через регулярное выражение `^\d{4}-\d{2}-\d{2}$`).
  - `cityId` должен существовать в `CITIES` (иначе — удалить запись из `visitedCities` как «мусор»).
  - `travelerName` должен быть строкой. Если нет — заменить на дефолтное.
- При обнаружении невалидных данных — молча очистить их и сохранить исправленное состояние.

### 1.5. Одновременные быстрые тапы

Пользователь может быстро тапнуть по двум разным городам в Каталоге или дважды по «Я здесь был». Это может вызвать двойное открытие карточки или двойной чекин.

**Защита:**
- Добавь флаг `let isProcessing = false;` (глобальная переменная).
- Устанавливай `true` в начале `openCityCard()`, `confirmVisit()`, `removeVisit()`.
- Сбрасывай `false` после завершения операции.
- Если флаг `true` при входе в функцию — `return` (игнорировать тап).

### 1.6. Поиск в Каталоге с нестандартными символами

Пользователь может ввести в поиск спецсимволы (`/`, `\`, `(`, `)`, `*`, `+`). Если поиск реализован через `RegExp` — это вызовет исключение.

**Защита:**
- Используй `string.includes(query.toLowerCase())` для поиска, а не `RegExp`. Если всё же нужен `RegExp` — экранируй спецсимволы через `query.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')`.

## Часть 3. PWA-упаковка

### 3.1. Файл `manifest.json`

Создай файл `manifest.json` в корне проекта:

```json
{
  "name": "Паспорт путешественника по Беларуси",
  "short_name": "Беларусь Паспорт",
  "description": "Коллекционируй штампы городов Беларуси",
  "start_url": "/",
  "display": "standalone",
  "orientation": "portrait",
  "background_color": "#ffffff",
  "theme_color": "#2c3e50",
  "icons": [
    {
      "src": "icon-192.png",
      "sizes": "192x192",
      "type": "image/png"
    },
    {
      "src": "icon-512.png",
      "sizes": "512x512",
      "type": "image/png"
    }
  ]
}
```

**Иконки:** сгенерируй простые PNG-иконки (192×192 и 512×512). Для MVP достаточно минималистичного логотипа — силуэт карты Беларуси или штамп на однотонном фоне. Если нет возможности сгенерировать PNG — создай SVG-иконку и используй её.

Добавь в `<head>` в `index.html`:
```html
<link rel="manifest" href="manifest.json">
<meta name="theme-color" content="#2c3e50">
```

### 3.2. Service Worker (`sw.js`)

Создай файл `sw.js` в корне проекта — минимальный Cache-First Service Worker:

```js
const CACHE_NAME = 'belarus-passport-v1';
const ASSETS = [
  '/',
  '/index.html',
  '/style.css',
  '/app.js',
  '/manifest.json',
];

self.addEventListener('install', (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME).then((cache) => cache.addAll(ASSETS))
  );
});

self.addEventListener('fetch', (event) => {
  event.respondWith(
    caches.match(event.request).then((response) => {
      return response || fetch(event.request);
    })
  );
});

self.addEventListener('activate', (event) => {
  event.waitUntil(
    caches.keys().then((keys) => {
      return Promise.all(
        keys.filter((key) => key !== CACHE_NAME).map((key) => caches.delete(key))
      );
    })
  );
});
```

Регистрация в `index.html` (в конце `<body>`, перед `</body>`):
```html
<script>
  if ('serviceWorker' in navigator) {
    navigator.serviceWorker.register('/sw.js');
  }
</script>
```

**⚠️ Важно:** PWA требует HTTPS. При локальной разработке через `localhost` Service Worker работает без HTTPS. Для продакшена — деплой на Vercel, Netlify или GitHub Pages (HTTPS по умолчанию).

## Часть 4. Финальная полировка

### 4.1. Сглаживание шрифтов
Добавь в `style.css`:
```css
html {
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
}
```

### 4.2. Предотвращение zoom при фокусе на инпутах
На iOS Safari инпуты с `font-size < 16px` вызывают auto-zoom. Убедись, что все `<input>` имеют `font-size: 16px` (или больше).

### 4.3. Tap highlight
Убери нативную подсветку тапа на мобильных:
```css
* {
  -webkit-tap-highlight-color: transparent;
}
```

### 4.4. Prevent pull-to-refresh
На мобильных браузерах pull-to-refresh может мешать скроллу. Добавь `overscroll-behavior-y: contain;` на главный контейнер.
